# Reference

## Background

Within InPreD, we are using different reference files as input for our processes. It is important that these files can be trusted to persist and be constant. Once an input file has been used to produce an output file used in our systems, the chain of tools and input needs to be reproducible, so that we can be sure that we are able to reproduce results at a later date. This calls for a library of reference files, and the first step is to make sure that we have a structured way of storing these files.

## Structure

We propose the following path for all reference files that were directly obtained from external sources:

`<source>/<identifier>/<version>/<filename>`

or

`<source>/<identifier>/<version>/<dirname>`

where the components of the path are defined as follows:

`<source>` denominates the generator/supplier of the reference files

`<identifier>` is a substructure that clearly identifies the type of reference files stored in the subpath

`<version>` is a unique identifier that clearly identifies different files from the same `<source>` and `<identifier>`

`<filename>` is the original file name from the upstream supplier

`<dirname>` is the directory name used by the upstream supplier

We will refer to the path consisting of `<source>/<identifier>/<version>` as `<reference_instance_dir>` or RID.
The `<reference_instance_dir>` must include the following metadata files, and only these:

- `README.md`: A file that describes
  - what reference files are present in the directory
  - from where (and, in case of modified files, how) the files have been obtained
  - the command used for retrieving the files initially
  - the person that retrieved the files, and in which capacity
- `md5sum.txt`: A file that lists the md5sums of the reference files contained within the directory. This will be used to automatically verify the consistency and identity of the reference files before use. This file should be generated by `find . -type f ! -path . -prune -name "*" ! -name md5sum.txt ! -path "*/\.git/*" ! -exec md5sum -b "{}" \; > md5sum.txt` and check it with `md5sum -c md5sum.txt`
